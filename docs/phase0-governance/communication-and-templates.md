# Cadence and templates (plan Phase 0, items 31–32)

- **Weekly team meeting**: progress per owner, deviations, decisions (append to `decision-log.md`).
- **Phase gates**: supervisor sign-off using each phase's exit criteria in the plan.
- **Templates in this repository**:
  - Run manifest: generated automatically (`runs/<id>/manifest.json`, hashed before registration).
  - Deviation report: `docs/protocol/deviation-log.md`.
  - Claim ledger: `docs/phase1-evidence/claim-ledger.csv`.
  - Decision log: `docs/phase0-governance/decision-log.md`.
  - Pre-/post-run checklists: `docs/protocol/checklists.md`.
