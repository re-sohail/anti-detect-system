# Run checklists (plan Phase 5, items 20–21)

## Pre-run
- [ ] Protocol version and schedule row identified: date ____ slot ____ order ____
- [ ] Collector reachable (Settings → collector URL; Network exits → Test)
- [ ] Guest/environment matches the schedule row; preset version noted
- [ ] Physical control: active consent record selected
- [ ] Vendor product: lawful-access basis recorded
- [ ] Route approved in the exit registry
- [ ] Host clock synchronised (macOS: `sntp -sS time.apple.com`; the collector records the offset per visit)
- [ ] Power source recorded (AC/battery) — the Performance screen samples it automatically on macOS

## Post-run
- [ ] Run status `complete` (else record why and whether a rerun is scheduled)
- [ ] Compare view reviewed; mismatches are kept as data, not fixed
- [ ] Network checks all `valid`
- [ ] Deviations recorded in `deviation-log.md`
- [ ] Schedule row status updated
